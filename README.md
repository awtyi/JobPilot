# JobPilot

一个面向个人求职过程的本地优先岗位管理与复盘工具。

## 项目定位

JobPilot 不是招聘平台，而是个人求职者的机会管理台。它帮助用户把分散在招聘网站、聊天记录和笔记中的岗位信息整理成一个可跟进、可复盘、可导出的工作台。

核心流程：

```text
采集岗位 -> 结构化 JD -> 管理进度 -> 复盘面试 -> 识别趋势 -> 导出报告
```

## 核心功能

- JD识别：粘贴 JD 原文后，本地规则拆分公司、岗位、地点、薪资、职责和要求。
- 岗位管理：支持表格、看板和卡片视图。
- 跟进提醒：首页展示今日待办，岗位列表支持跟进截止日筛选。
- 阶段时间线：记录岗位创建、阶段变化、结束原因和恢复操作。
- 面试复盘：按岗位记录面试轮次、问题、回答摘要、反馈和改进动作。
- 求职画像：维护目标方向、技能、地点和薪资期望，计算画像建议分。
- 数据分析：查看阶段漏斗、方向分布、渠道分布和高频关键词。
- 导入导出：支持 JSON 备份恢复、CSV 导出和 Markdown 周报。
- 首次引导：第一次打开时展示五步操作指引，可在设置页重新查看。

## 数据与隐私

JobPilot 当前版本采用本地优先策略：

- 岗位、薪资、面试和备注默认保存在浏览器本地。
- JD 识别使用本地规则，不默认发送到外部服务。
- JSON 备份由用户自行导出和保管。
- 未来如接入云端 AI 分析，应先提示用户确认上传字段。

## 推荐试用路径

1. 打开工作台，看今日待办和 A 级重点机会。
2. 点击 JD识别，粘贴一段 JD 并识别。
3. 保存岗位，进入岗位机会列表。
4. 使用跟进截止日和优先级筛选岗位。
5. 切换看板并拖动岗位阶段。
6. 打开岗位详情查看时间线和 JD 重点。
7. 新增一条面试复盘。
8. 进入设置维护个人求职画像。
9. 导出 Markdown 周报或 JSON 备份。
